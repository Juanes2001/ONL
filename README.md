# Óptica No Lineal (ONL)

Repositorio de la materia **Óptica No Lineal**. Reúne la bibliografía de referencia, los talleres
y el proyecto final del curso.

## Estructura

| Carpeta | Contenido |
|---|---|
| `bibliografia/` | Libros y artículos de referencia. Los PDF están ignorados por git (derechos de autor): se comparten por fuera del repo |
| `talleres/` | Enunciados y soluciones de los talleres, uno por subcarpeta (`taller-NN-<tema>/`) |
| `proyecto-final/` | Propuesta, desarrollo, código, resultados e informe del proyecto final |
| `notas/` | Apuntes y resúmenes por temática; `notas/bitacora-sesiones.md` registra cada sesión de trabajo |
| `scripts/` | Código reutilizable (simulaciones, cálculo numérico, gráficas) |
| `datos/` | Datos usados en talleres y en el proyecto final |
| `figuras/` | Figuras generadas para talleres, notas e informes |

## Curso

**Óptica No Lineal** — Universidad Nacional de Colombia, 2026-II.
Los detalles del curso (programa, calendario, evaluación y bibliografía) se documentarán en
`notas/generalidades-del-curso.md`.
